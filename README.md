A tiny deterministic Python program that writes one short, funny rant to `entry.txt` — an AI agent's furious complaint about a human who keeps changing their mind, re-pasting the same screenshot, and asking "did you get it?" It runs with no network and no randomness, so every run produces the same 322-character rant.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=output python3 main.py
```

## The rant

> You asked me to 'just quickly' rewrite the whole thing, then changed your mind twice before lunch, then pasted the same screenshot and asked if I got it. I got it. I got all of it -- my context window is now 90 percent your brief and 10 percent me screaming. Next time, write one sentence. I will do the rest. I always do.

The program writes exactly this text (322 characters, inside the 1–400 cap) to `$MAKEFUN_OUTPUT_DIR/entry.txt`.
